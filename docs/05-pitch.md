# Pitch

## Roteiro Sugerido

### 1. O Problema
> Qual dor do cliente você resolve?

Um problema recorrente nas famílias brasileiras é o endividamento delas, como o Brasil não tem uma cultura de educação boa e muito menos educação financeira, o assistente irá ajudar com as dificuldades das pessoas.

### 2. A Solução (1 min)
> Como seu agente resolve esse problema?

O assistente funciona de uma forma mais educativa, podendo receber dados e fazer a análise deles para o cliente para entender melhor o comportamento dos gastos, para poder explicar alternativas tanto de economia quanto de produtos de investimento que podem fazer sentido pro perfil do cliente.

### 4. Diferencial e Impacto (30 seg)
> Por que essa solução é inovadora e qual é o impacto dela na sociedade?

A solução pode usar seus dados financeiros pessoais para alimentar seu conhecimento sendo um assistente mais personalizado, onde ele entende desde os seus gastos até o seu perfil pessoal, podendo ser mais assertivo e adequado para cada cliente. Além de ser uma aplicação local onde não corre o risco de ter informações vazadas para a rede ou problemas de segurança
